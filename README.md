# TravelOptim Madrid

**Interactive bilingual travel guide for Madrid 🇪🇸**  
**Guide de voyage interactif bilingue pour Madrid 🇪🇸**

---

## 🇬🇧 English

TravelOptim Madrid is a bilingual web application designed to help visitors discover Madrid, organize their visits and make the most of their time in the city.

### Main features

- 🏛️ Interactive Madrid guide
- 🧭 14 curated itineraries
- 🗺️ Interactive map with points of interest and Metro network
- 📍 Search, geolocation and nearby places
- ❤️ Favourite places
- ✈️ Personalized trip-planning request
- 🌐 French / English interface

### Technologies

HTML5 • CSS3 • Vanilla JavaScript • Leaflet • MapLibre GL • OpenFreeMap • GeoJSON • Formspree
